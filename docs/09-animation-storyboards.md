# 09 · 逐课教学动画分镜

配套：[美术规范](08-art-and-animation.md)、[课程体系](02-curriculum.md)。

课号与 [src/data/lessons.ts](../src/data/lessons.ts) 一致。文中的示例数据都是教学素材，不是产品运行测试结果。

## 0. 状态来源

当前版本所有图示都来自 **E：本次真实解释执行**。没有使用教学模型。

- **E**：解释器实际提供的状态。图示只能画引擎确实给出的事实。
- **M**：受控教学模型（本版未启用）。若将来引入，源码被手工编辑后模型必须立即失效并提示。
- **A**：作者维护的结构图（本版未启用）。绑定课程版本，不声称自动分析任意项目。

## 通用约束

1. 停点行高亮表示解释器位置，**同一行的表达式可能产生多个状态**，不能讲成「这一行只执行了一步」或「这就是求值顺序」。
2. 数组游标由索引变量绘制，是教学指示，**不代表检测到一次内存读取**。
3. 未初始化值显示「未初始化」，不写 `0`。
4. 数值变化直接替换，不滚动计数；不得凭空出现中间值。
5. 指针用逻辑对象标签，不生成编造的十六进制地址。
6. 回退只恢复已记录状态，不撤销真实副作用（如已产生的输出）。
7. 同一变量名的不同作用域实例必须分别显示，不能合并成一个盒子。

## 01 · 一行输出如何出现

- **对象**：源码位置、输出窗口。
- **动作**：运行 → 当前语句聚焦 → 本次输出文本整体追加 → 标记执行结束。
- **解释**：这段代码把文本写入输出，输出内容来自本次执行。
- **修改**：更换输出文字、增加第二条 `printf`。
- **误区**：删去分号，定位语法错误，不播放成功输出。
- **验收**：没有逐字符打字动画暗示系统执行时序。

## 02 · 赋值复制的是值

- **对象**：a、b 两个变量盒。
- **动作**：`b = a` 时聚焦 a → b 改值并显示前后对比 → 随后 `a = 7` 只改变 a。
- **解释**：b 得到当时 a 的值，之后两个变量各自独立。
- **提问**：「a 变成 7 后，b 是多少？」
- **验收**：修改 a 时 b 的显示不跟随变化。

## 03 · 判断选择路径

- **对象**：score 变量、比较结果、输出区。
- **动作**：比较结果出现 → 强调被选中的一侧 → 未选中的一侧保持静止并标注未执行。
- **修改**：score 取 59 / 60 / 61，观察边界差异。
- **验收**：false 不渲染成程序错误；不同时播放两条分支。

## 04 · 循环的节奏

- **对象**：初始化、判断、循环体、更新四阶段；i 与 sum。
- **动作**：每一步只强调一个阶段；i 递增后回到判断。
- **终态**：条件为 false 时退出，不再执行循环体。
- **修改**：把 `<=` 改成 `<`，比较多出或缺失的一次迭代。
- **验收**：迭代次数不等于条件判断次数；初始化不每轮重播。

## 05 · 数组与遍历

- **对象**：数组格、索引行、索引游标、sum 变量盒。
- **动作**：游标移动到当前索引 → 该格聚焦 → sum 显示前后值。
- **终态**：索引越界时不生成新的数组格，只在边界处停止。
- **修改**：数组元素与循环上界。
- **验收**：索引显示在值区域之外；游标不遮挡数字；数组长度不因滚动窗口而改变。

### 详细样板：数组累加

数据 `scores = [72, 85, 93, 68, 102]`，求和循环。

| 步骤 | 阶段 | i | sum 前→后 | 图示状态 |
|---|---|---:|---|---|
| S0 | 初始化 | 0 | 0→0 | 数组出现，游标指向第 0 格 |
| S1 | 判断 | 0 | 0→0 | `0 < 5` 为真 |
| S2 | 累加 | 0 | 0→72 | 第 0 格与 sum 同时聚焦 |
| S3 | 更新 | 1 | 72→72 | 游标平移到第 1 格 |
| S4–S6 | 重复 | 1→2 | 72→157→250 | 依次处理第 1、2 格 |
| … | | | | 每轮重复判断—累加—更新 |
| S15 | 更新 | 5 | 420→420 | 游标到达边界之外 |
| S16 | 判断/结束 | 5 | 420→420 | 条件为假，退出 |

S2 的一次教学动作约 900 ms：聚焦语句与目标格（0–140 ms）→ 显示已知输入 → 替换 sum 并展示 `sum: 0→72` → 暂留前后值供讲解。

- 提问停点放在 S2 之前：「第一次累加后 sum 是多少？」
- 跳转到任意步骤直接呈现目标状态，不补播之前所有轮次。
- 若把上界改成 `<= 5`，只在确实越界的位置提示风险，不凭空生成一个元素值。

## 06 · 函数与传值

- **对象**：main 调用层、被调函数层、参数盒、返回值。
- **动作**：新调用层出现 → 参数接收值的副本 → 返回值进入调用者 → 函数层收起。
- **传值变体**：函数内修改形参，调用者的变量保持原值。
- **验收**：不把两个实参的复制顺序讲成标准规定的求值顺序；同名局部变量分别显示。

## 07 · 字符串的结尾由终止符表示

- **对象**：字符数组格、终止符标记、输出区。
- **动作**：打印时逐格前进，遇到 `\0` 停止。
- **解释**：数组容量是 6，字符串长度是 5；终止符占一格但不算长度。
- **验收**：终止符用专门标签显示，不能误画成字符 `'0'`。

## 08 · 改指向与改目标是两件事

- **对象**：x、y、指针盒 p 与指向箭头。
- **分镜 A**：`*p = 7` → x 改变，箭头不动。
- **分镜 B**：`p = &y` → 旧箭头淡出，新箭头连接到 y，x 保持不变。
- **分镜 C**：`*p = 11` → 只改变 y。
- **验收**：仅凭静态终态也能分辨两类变化；指针盒始终可见。

## 09 · 输入与交互

- **对象**：输入面板、变量盒、输出区。
- **动作**：运行前读取预设输入 → 变量依次出现 → 输出结果。
- **解释**：`scanf` 需要知道把读到的数据存到哪里，因此传入变量地址。
- **修改**：只改输入面板，不改源码，重新运行验证。
- **验收**：输入不足时不猜测剩余变量值，显示程序自己的提示分支。

## 10 · while 与循环控制

- **对象**：i、循环阶段、输出行。
- **动作**：`continue` 回到条件判断，不播放本轮后续语句；`break` 直接离开循环。
- **修改**：移除跳过偶数的判断，预测输出差异。
- **验收**：`break` 之后不播放更新操作；条件为假时不再执行循环体。
