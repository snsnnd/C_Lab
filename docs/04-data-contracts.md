# 04 · 轻量课程与动画数据协议

## 1. 原则

复用引擎已有协议，只增加一层小而稳定的教学适配。此文为字段设计草案，不是要求重建完整调试系统。

### 当前实现：多文件字段

下文的通用协议仍为设计草案；当前代码以 `src/engine/types.ts` 为准：

- `Lesson.code` 是 main.c，`Lesson.files?` 保存额外 .c/.h 文件。
- `Draft` 保存 `code`、`input`、可选 `files`。旧的单文件草稿仍可读取。
- Worker 接收 `{ source, input, files? }`；存在 `files` 时，它是包含 main.c 的完整文件映射。
- `Trace.files?` 保存本次运行的完整项目版本；任一文件或输入发生变化都会使回放过期。
- `Snapshot.file?` 和 `Snapshot.line` 指向原始源码；`Frame.file?` 标识调用实现所在文件；诊断通过 `errorFile/errorLine` 定位。
- 完整项目导出为 `{ "files": { "main.c": "...", "module.h": "...", "module.c": "..." }, "input": "..." }`，单文件仍导出 .c。
- 模块包含关系从源码 include 提取；实际调用信息来自快照，两者分别展示。
- `Trace.preprocessed?` 仅当源码包含宏定义、条件编译或 `#undef` 时出现，保存每个翻译单元展开后的源码，供「查看预处理结果」展示。它不参与回放定位；快照与诊断始终映射原始文件与原始行。

## 2. 一次教学运行

| 字段 | 意义 |
|---|---|
| `sessionId` | 本次实验身份 |
| `sourceRevision` | 代码/参数的不可变版本 |
| `mode` | `code`、`guided`、`architecture` |
| `origin` | `engine`、`lesson-model`、`authored-diagram` |
| `capabilities` | 本次实际可展示的变量/数组/调用等能力 |
| `steps` | 有序状态步骤；可逐块生成 |
| `status` | 准备、生成、可播放、失败、停止、截断 |

步骤包含：`stepId`、可选源码范围、已知数据、变化摘要、说明文本引用、关注对象、可选提问停点。

不能取得的信息留空并说明原因。代码位置可以是一组范围，不假设每一行对应唯一步骤。

## 3. 动画描述与数据分离

逻辑步骤保存 before/after 状态；动画描述包含图元 ID、起止位置、持续时间、缓动和阶段顺序。

- 暂停位置由步骤和阶段进度决定。
- 下一步先完成当前教学步骤，再切换到下一步。
- 上一步恢复上一逻辑状态，不把函数返回倒放成真实调用。
- 拖动时间轴直接展示目标状态，不排队播放中间所有动画。
- 数值变化直接替换，不能把 3→6 动画为经过 4、5 的连续计数。
- 自有图元采用稳定 ID；同名局部变量使用调用实例区分。
- 概念对象地址用 `obj-1` 等标签；不生成伪造十六进制地址。

## 4. 课程包

```text
lessons/C06-array/
  lesson.json
  notes.zh-CN.md
  teacher-notes.md
  examples/
  diagrams/
  storyboard.json
  expected-results.json
```

课程元数据：课号、目标、前置知识、源码文件、预设输入、所需能力、默认视图、正常/误区变体、受控参数、演示来源和版本。

`storyboard` 使用 [动画规范](08-art-and-animation.md) 的动作词：出现、聚焦、复制、移动、替换、连接、断开、返回、退出。无需为每课写一个新动画引擎。

课程包只能携带数据与受控资源，不携带任意可执行 JS 插件。

## 5. 架构图数据

节点：模块名、职责、源文件、公开接口、版本身份。

边：`depends-on`、`calls`、`returns`、`implements`，使用不同样式与文字。

标注：`authored=true`，绑定项目版本；重构前后使用稳定的职责 ID 做映射。

“新增按姓名排序”场景的改动文件必须来自实际两个示例版本的差异，不人为填一个好看的耦合分数。

## 6. 保存与失效规则

- 用浏览器本地存储/IndexedDB 或底座现有工作区保存；导出课程引用、源文件、输入与参数。
- 导出不依赖云账号；运行环境信息随参考轨迹保存。
- 编辑代码立即标记旧步骤为过期，不覆盖上次成功结果。
- 引擎与课程模型不得共用不带来源的轨迹缓存。
- 打开旧协议版本时给出迁移或只读提示，不能静默错误回放。
