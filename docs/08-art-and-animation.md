# 08 · 美术、视觉与教学动画规范

版本：v0.2 设计提案。对象：大一新生、课堂投屏、课后笔记本学习。此文规定制作目标，尚无已实现页面或实测动画；最终字号与节奏要通过教师试讲确认。

配套：[逐课分镜](09-animation-storyboards.md)、[课程表](02-curriculum.md)、[数据协议](04-data-contracts.md)。

## 1. 美术方向

**清晰的二维教学白板：代码像教材，数据像可操作的图形，变化像教师逐步板书。**

界面的主要任务是让学生理解代码执行或模块关系。课堂灯光较亮、投影对比有限，因此以浅色高对比为默认；课后可选暗色。

视觉特征：

- 大部分区域安静、平面化；只有当前讲解对象被强调。
- 变量用盒，数组用连续格，指针用有方向的连接，函数用有次序的调用层，模块用有职责标题的区域。
- 数值与对象标签稳定，随状态更新；不要让整个画面每一步重新排版。
- 不采用卡通人物、拟物传送带、霓虹背景、粒子、3D 房间或无意义弹跳。
- 课程完成反馈只需清楚确认和下一课入口，不使用烟花或持续吸引注意的庆祝动画。

**记忆点**：学生应记住“i 指到哪个格、sum 如何变化、哪个模块依赖哪个接口”，而不是按钮的特效。

## 2. 构图与屏幕规格

### 2.1 桌面标准稿：1440 × 900

| 区域 | 建议规格 | 内容 |
|---|---|---|
| 顶部工具栏 | 高 56 px | 当前课、模式、运行、恢复、投屏 |
| 主工作区 | 剩余主体空间，左右默认 48% / 52% | 代码与主图 |
| 文件/视图栏 | 各高 40 px | 源文件标签；主图标题、来源标签 |
| 步骤解释 | 右侧底部预留约 72 px，可随字号增高 | 一句解释、前后值、提问 |
| 播放器 | 高 56 px | 前进、回退、播放、速度和时间轴 |
| 输出区 | 默认 140 px，可折叠与拖高 | 输入/输出/错误/讲义 |

这些尺寸是设计基线，不是绝对定位坐标；容器必须适应浏览器缩放和大字体。

- 两栏最小有效宽度建议各 420 px，分隔条有至少 12 px 可抓取区域。
- 课程导航用抽屉，不固定占第三栏。
- 右侧标题、图例和解释固定在各自区域，主图变化不挤压控制条。
- 超宽屏不无限放大空白，主图保持可聚焦范围；允许代码与图示比例变化。

### 2.2 投屏：1920 × 1080 与 1366 × 768

- 投屏模式将代码/主要图示标签提高到 22–24 px，次级标签不小于 18 px。
- 收起输出和目录后，把高度留给代码与图形；需要讲输出时再展开。
- 代码较长采用滚动并锁定当前片段，不把字号缩到不可读。
- 一屏只讲一个概念，主图同时突出不超过 3 个关联对象。
- 不以远处学生难以分辨的 1 px 浅灰线承载关键关系。

### 2.3 窄屏

- 宽度不足约 960 px 时，切换“代码 / 图示”标签，保留步骤说明和播放器。
- 手机可读讲义、看参考轨迹；不是首版长代码编辑的主要优化目标。
- 图示过宽使用局部滚动/聚焦窗口，不把所有字体整体缩小。

## 3. 色彩系统

### 3.1 主题 token 草案

| Token | 浅色 | 暗色 | 用途 |
|---|---|---|---|
| `canvas` | `#F4F6F8` | `#111827` | 工作台底色 |
| `surface` | `#FFFFFF` | `#1F2937` | 代码/图示平面 |
| `text-primary` | `#172B3A` | `#F3F4F6` | 正文、数值 |
| `text-secondary` | `#526170` | `#CBD5E1` | 说明、类型 |
| `border` | `#C8D1DB` | `#64748B` | 非语义分隔 |
| `accent` | `#165DCC` | `#93C5FD` | 当前焦点、执行位置 |
| `accent-fill` | `#E8F0FE` | `#20395B` | 活动对象背景 |
| `changed` | `#965A00` | `#FCD34D` | 值刚发生变化 |
| `changed-fill` | `#FFF4D6` | `#493810` | 改值提示底色 |
| `success` | `#176B46` | `#86EFAC` | 完成、验证通过 |
| `error` | `#B42318` | `#FDA4AF` | 错误、非法访问提示 |

主要操作采用一个蓝色强调色；变化、成功、错误是语义颜色，不扩展成多彩装饰。

表中为候选 token，必须检查实际前景/背景组合。普通文字至少 4.5:1，必要图形轮廓和焦点至少 3:1；`border` 只做装饰分隔，关键箭头与对象边界使用较深的文字/语义色。

本轮已按 WCAG 相对亮度公式检查两主题的正文/面板、次级文字/面板、强调文字/强调底色、变化文字/变化底色、成功文字/面板和错误文字/面板，共 12 组；比值约 5.10:1–14.55:1，均超过 4.5:1。这仅验证列出的静态色对，不替代实际页面的按钮、焦点、叠层和投影检查。

### 3.2 同一状态至少两种编码

| 状态 | 颜色之外的识别方式 |
|---|---|
| 即将执行 | 行号边箭头 + “下一步”文字 |
| 最近完成 | 实线侧标 + “刚执行”标签 |
| 数值改变 | 明确的 `旧值 → 新值` 摘要 |
| 未执行分支 | 虚线 + “未执行”标签 |
| 未知值 | `?` + “未知”，不写 0 |
| 空指针 | `NULL` 终点标签，无目标连线 |
| 无效/超界 | 警示图标 + 具体文字 |
| 课程模型 | 固定“教学模型”来源标签 |

true 和 false 不使用绿/红表示正确/错误：两个分支都可能是正常结果，使用 `true`/`false` 标签和选中路线区分。

## 4. 字体、数字和留白

- 中文：系统无衬线优先，可提供本地 Noto Sans SC 子集；避免在线字体依赖。
- 代码与值：JetBrains Mono 或系统等宽回退；保留字体许可证。禁用编程连字，确保 `!=`、`->` 等字符对初学者可辨。
- 标题 20–24 px，正文 16–18 px，代码 18 px 起，主图数值 24–32 px，辅助标签一般 14–16 px。
- 代码行高约 1.6；正文约 1.5。投屏模式按上一节放大。
- 数字使用等宽数字；值变长时预留槽位，不能让其他对象被推走。
- 间距采用 4/8/12/16/24/32 px 层级。对象内部至少 12 px 留白，图元之间至少 24 px。
- 常规盒子圆角 8 px；主面板不靠大圆角制造装饰。条件节点使用菱形或明确的条件标题。
- 常规轮廓 1.5–2 px，选中轮廓 3 px；投屏关键边建议 2–3 px。
- 文案长时优先换行或展开，不用只在 hover 才能看到的截断承载必要信息。

## 5. 基础图元规格

所有规格为 100% 缩放下的建议起点，必须自适应中文长度。

| 图元 ID | 外观/建议尺寸 | 必需信息 | 注意事项 |
|---|---|---|---|
| G01 变量盒 | 136×88 起，名称在上、值居中、类型在下 | name、value、type、status | 值与变量身份分离 |
| G02 值副本 | 64×36 起的小标签 | 值及“副本”语义 | 复制时源盒仍保留值 |
| G03 数组格 | 每格 64×64 起，索引独立一行 | index、value、选中状态 | 相邻格连续；索引不画进值区域 |
| G04 索引游标 | 三角/短箭头 + `i=2` | 当前索引 | 指向格子，不遮住数字 |
| G05 条件节点 | 160×80 起 | 表达式、结果 | 路线端口明确 true/false |
| G06 循环阶段 | 4 个有编号的阶段 | 初始化/判断/循环体/更新 | 不暗示 do-while 与 for 顺序一样 |
| G07 函数调用层 | 280×140 起的帧 | 函数、调用序号、参数、局部量 | 同名递归调用也有不同身份 |
| G08 指针盒 | 160×88 起 + 连接端口 | 名称、目标标签、状态 | 不显示编造的机器地址 |
| G09 结构体记录 | 240 px 宽起，字段按行 | 对象名、字段名/类型/值 | 声明顺序，不表示物理偏移 |
| G10 枚举状态 | 圆角节点，最小 128×64 | 名称和可选数值 | 数值只在实际确定时展示 |
| G11 模块区域 | 220×144 起 | 模块名、职责、公开接口 | 区分模块边界和函数盒 |
| G12 接口插槽 | 模块边缘标签或连接口 | 接口签名/角色 | 替换实现时接口位置不变 |
| G13 输出行 | 等宽文本行 | 实际文本与追加顺序 | 不用打字动画伪造输出时序 |
| G14 变化摘要 | 图下固定条 | 对象名、旧值、新值 | 可读屏，不只短暂闪现 |

## 6. 箭头与图形语法

不同图的边不能随意复用同一种动画含义。

| 边 | 画法 | 意义 |
|---|---|---|
| 指针关系 | 常驻实线单箭头，贴目标对象边缘 | 指向对象，线本身不流动 |
| 值复制 | 临时细路径 + 值副本标签 | 值被复制，源值未移走 |
| 控制流 | 路径 + 当前步骤标记 | 下一步执行路线 |
| 模块依赖 | 静态实线，标签“依赖” | 使用某个接口的结构关系 |
| 实际调用 | 单次路径强调，标签“调用” | 本次已观察到的调用 |
| 返回 | 反向虚线，标签“返回” | 返回控制/结果，不撤销参数复制 |
| 实现关系 | 虚线连接接口，标签“实现” | 实现接口约定，不代表每次运行都会调用 |

- 同屏图例必须匹配正在使用的边类型。
- 线不穿过对象文字；交叉多时聚焦选中节点的一跳邻居。
- 首版一个架构视图建议不超过 6 个模块、10 条关系；更多内容按层展开。
- 不使用持续移动的小光点表示静态模块依赖，否则容易被理解为实际执行。

## 7. 动画节奏与动作词

### 7.1 三种时间

1. **状态时间**：程序/模型第几步，决定事实。
2. **讲解时间**：为了让人看懂，将一步拆成聚焦、变化和解释。
3. **播放时间**：用户选定速度，决定观看快慢。

讲解拆分不自动代表实际机器指令或表达式求值顺序。

### 7.2 动作词表

| 动作 | 建议时间 | 运动规则 | 传达含义 |
|---|---|---|---|
| 出现 | 160–220 ms | 透明度 0→1，至多 8 px 位移 | 新声明对象/新调用出现 |
| 聚焦 | 120–160 ms | 边框/底色变化 | 看这里 |
| 复制 | 280–360 ms | 副本沿短路径移动，原值保留 | 赋值/传参 |
| 替换 | 120–180 ms | 值直接切换或淡入淡出 | 状态更新，不连续计数 |
| 游标移动 | 220–300 ms | 相邻格平移，不弹跳 | 索引改变 |
| 连接/改指向 | 200–280 ms | 旧边淡出，新边淡入 | 引用关系改变 |
| 调用展开 | 240–320 ms | 新帧出现，调用者位置稳定 | 进入函数 |
| 返回/退出 | 200–280 ms | 返回值先确认，帧再收起 | 生命周期或调用结束 |
| 模块替换 | 300–450 ms | 实现区替换，接口和调用方固定 | 接口稳定、实现可变 |
| 提问停点 | 无自动计时 | 暂停并显示问题 | 学生先预测 |

单个普通教学步骤建议 600–1000 ms，复杂调用 1000–1500 ms；这是几个动作的组合，不要求所有动作同速。

缓动：普通 UI 用 ease-out，值副本沿路径匀速或轻微 ease-in-out；避免回弹、超调和惯性，以免形成不存在的中间状态。

### 7.3 播放控制

- 默认 1×，提供 0.5× / 1× / 1.5× / 2×；关键提问点在任何速度都停下。
- 点击下一步只跨一个逻辑步骤，复杂动作在内部串行完成。
- 暂停冻结当前阶段；不能只改按钮图标而任由副本继续飞。
- 再次运行取消旧动画、重建版本，不让旧对象的回调写入新状态。
- 快速跳转直接定位目标状态，至多做短促聚焦；禁止补播全部中间步骤。
- 上一步恢复上个快照及说明。返回值、输出均展示“该快照时刻”的内容，避免被误解为撤销真实副作用。

## 8. 常见概念的动画规则

### 8.1 赋值与表达式

`b=a`：a 保留，值副本从 a 移到 b，b 改值。随后修改 a，b 不跟随变化。

`sum=sum+x`：聚焦已知输入 → 显示已验证的计算关系 → 替换 sum → 固定显示前后摘要。数值不滚动计数；表达式拆分只有引擎证据或课程模型允许时才展示。

### 8.2 条件与循环

条件结果出现后，再强调所选路径。未走分支静止且标注“未执行”。循环每轮保持数组和变量位置，只有阶段与索引变化。

`continue` 的目的地由循环种类决定，不能共用错误分镜；`break` 直接到循环外，不能先播放更新操作。

### 8.3 数组与字符串

索引在格下，值在格内。访问时先强调游标与目标格的关联，再显示结果。

末端之外画明确的边界区域，不生成看似可读写的新格。字符串的 `\0` 用可见符号标签表示，不画成一个普通可显示字符。

### 8.4 函数与指针

传值通过副本进入新参数盒。指针参数也先复制指针值，再用两个箭头指向同一目标，不能画成对象本身被复制两份。

改变 `p` 只改变连线，改变 `*p` 只改变目标内容；p 盒必须一直可见。未知目标用文字说明，不猜测连接。

### 8.5 架构与回调

把流程模块与策略实现放在稳定区域，接口位置固定。切换比较规则仅替换实现标签和对应源码；调用轨迹显示实际或课程声明的时序，明确来源。

重构对照先展示职责和依赖，再展示实际文件变更；不把“框更多、线更少”直接判定为架构更好。

## 9. 画面状态与错误文案

| 状态 | 画面处理 | 示例文案 |
|---|---|---|
| 未运行 | 预留图区域与示例提示 | “运行代码，观察变量如何变化” |
| 生成中 | 保持布局，显示已知进度；未知时不报假百分比 | “正在准备本次执行” |
| 已修改 | 旧画面覆盖轻量状态条 | “图示来自上次运行，请重新运行” |
| 编译/解析失败 | 错误定位源码，旧图不当成新结果 | “此处缺少分号”并保留原消息 |
| 能力不支持 | 展示能力说明与可用入口 | “当前引擎不支持此语法，可导出源码运行” |
| 超时/截断 | 停止动画，保留最后可信状态 | “已到步骤上限，轨迹不完整” |
| 模型失效 | 停止模型播放 | “代码已超出本课模型支持范围” |
| 运行结束 | 不弹全屏遮罩 | “运行结束，结果为 240” |

不要用页面抖动、警报音或大面积红色惩罚初学者。

## 10. 可访问性与性能

- 图示同时提供“变量/关系/变化”文本列表；不可把关键信息只画在 Canvas 中。
- 提供减少动态效果开关并尊重系统偏好：取消移动，保留逐步状态和前后值。
- 屏幕阅读器在手动单步时播报摘要；自动快放不逐帧刷屏。
- 控件触达建议至少 44×44 px；焦点明显，播放快捷键不抢编辑器键盘。
- 不提供默认音效；教师语音已经是课堂的主要听觉通道。
- 第一版优先 DOM/SVG，控制同时可见对象数量。长数组窗口化，调用层过多时折叠旧帧。
- 数组窗口切换必须提示“显示第 8–15 项，共 40 项”，不能让学生误认为数组长度变化。
- 动画优先 transform/opacity；短小 SVG 路径强调可单独测量，避免大范围逐帧布局。
- 设计目标为普通笔记本流畅播放，实际帧耗时和交互延迟在样板课实现后测量；当前未做性能测试。

## 12. 视觉验收

1. 投屏后，学生能区分代码位置、对象和值；中文与数字没有裁切。
2. 暂停任意步骤，画面本身能解释当前状态，不依赖刚刚看过的运动。
3. 复制不会让源值消失，改值不会生成中间假数值。
4. 指针改向和解引用写入的运动明显不同。
