# 01 · 轻量教学产品设计

## 1. 当前范围

当前包含 **23 节课程：14 节 C 语言基础、4 节软件架构、4 节常用进阶用法，以及 1 个最终章综合系统**。

软件架构通过可编辑、可运行的多文件 C 项目讲解模块化、封装、分层与策略替换。左侧文件栏支持增删、重命名和切换；跨模块回放自动定位原文件原行。所有文件与输入本地保存，并可整体导入导出。

进阶课覆盖宏定义与展开、条件编译、静态局部变量与位标志、动态内存。宏课可展开「查看预处理结果」，对照展开代码与原始高亮行；宏不产生调用帧。最终章的学生成绩管理系统由 7 个文件组成，通过命令式输入完成增删改查与统计。

播放控制提供键盘快捷键与页脚帮助入口。输入焦点保留文本编辑键，Alt + 方向键可在编辑器内单步，Ctrl/⌘ + Enter 运行，Ctrl/⌘ + . 停止。

## 2. 好不好做？

「完整 C 调试器 + 任意源码自动动画」难度高；「基础 C 交互教学 + 复用成熟执行器」难度中等。

当前已完成的取舍：**解析复用 tree-sitter-c（MIT），执行与轨迹由本项目自研求值器实现**，自有代码覆盖**课程内容、执行轨迹、教学图示和课堂体验**。原本设想的「直接复用现成解释器」在实测后不成立——没有浏览器内的 C 引擎同时支持结构体、枚举与函数指针（见 [07](07-open-source-review.md)）。

## 3. 三种明确区分的交互

### A. 代码实验（当前唯一的主模式）

用户自由编辑底座支持的代码，实际解释执行，显示变量、数组、指针与调用状态。标注「浏览器本地解释执行」，不标成「本机真实地址」。

### B. 课程讲义

每课提供概念说明、预测题、参考解释与动手任务。学生先预测，再运行，再解释。

### C. 教学模型（当前未启用）

受控参数生成的场景动画，例如改变数组元素后重新计算模型。当前版本所有图示都来自真实执行，没有使用教学模型，因此不存在「模型冒充执行」的风险。若后续引入，源码被手工编辑后模型必须立即失效。

## 4. 工作台

```text
课程 / 当前课              浏览器本地运行   目录  投屏  主题  设置
┌──────────────────────────┬──────────────────────────────────┐
│ 代码实验 | 本课讲义  自动运行  恢复示例  运行 │ 视图: 图示 | 状态表 │
├──────────────────────────┼──────────────────────────────────┤
│ main.c   导入 / 导出     │ 运行可视化            当前行号   │
│                          │                                  │
│ CodeMirror C 编辑器       │ 数组格 + 索引游标               │
│ 当前停点行高亮            │ 变量盒 + 本步变化高亮            │
│                          │ 指针指向 / 嵌套调用层            │
├──────────────────────────┼──────────────────────────────────┤
│                          │ 本步解释：具体哪个值变了          │
├──────────────────────────┴──────────────────────────────────┤
│ ⏮ ◀ ▶ ▶|  4 / 21 步   ──────●────────────  速度 1×         │
├─────────────────────────────────────────────────────────────┤
│ 输出 | 输入 | 诊断                          执行结束 · 15 ms │
└─────────────────────────────────────────────────────────────┘
```

- 默认两栏接近等宽；窄屏（< 960 px）切换「代码 / 可视化」标签。
- 课程目录用抽屉，不固定占第三栏。
- 图形区高度不足时可滚动，视图会自动把本步变化的对象滚动到可见位置。
- 「函数调用」区块仅在存在嵌套调用时出现，避免单层 `main` 时产生噪音。

## 5. 实时与错误处理

- 编辑时不做自动运行；点击「运行代码」或按 `Ctrl / ⌘ + Enter` 生成轨迹。
- 可选开启「自动运行」，代码或输入停止变化约 800 ms 后重新执行。
- 源码或输入一旦修改，旧图示立即标记为「来自上次运行」，并降低不透明度。
- 不支持的语法、无效输入、执行超时、输出超限分别给出明确说明，保留原始信息。
- 暂停与回退只控制已有轨迹；程序已运行完毕，输出窗口显示本次完整输出且不随回放撤销。

## 6. 课堂学习流程

预测结果 → 单步观察 → 用自己的话解释 → 修改一个条件 → 再预测 → 标记学完。

投屏模式放大代码与关键数值；深浅主题与减少动画开关照顾不同教室环境。
