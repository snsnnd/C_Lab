# 03 · 技术路线与模块边界

## 1. 推荐决策

**解析交给 tree-sitter-c（WASM），执行与教学事件由本项目实现。**

选型经过实测而非推断：JSCPP 缺 struct/enum/函数指针，persistent-c 与 Codecast 都依赖原生二进制与服务器，无法满足「浏览器内、学生自由改代码、纯静态部署」。完整证据见 [07](07-open-source-review.md)。

编辑器、播放器、课程与图示全部自有，没有底座平台需要剥离。

## 2. 数据流

```text
课程包 / 学生源码
       ↓
本项目预处理器（src/engine/c/preprocess.ts）：注释与续行、宏展开、条件编译、include 与原始行映射
       ↓
tree-sitter-c（WASM）→ CST → 本项目 AST（类型检查、声明符绑定、枚举常量替换、按源码计算行号）
       ↓
逐步求值器（Web Worker）：字节内存 + 栈/堆/静态区 + 标准库
       ↓
StepEvent 流（语句停点 / 分支决策 / 调用与返回 / 分配与释放）→ Trace（快照、控制流、输出、结构体布局、平台信息）
       ↓
教学视图：变量 / 数组 / 结构体 / 指针 / 调用 / 回调
       ↓
统一播放器、解释文字、文本替代视图
```

预处理器按翻译单元工作：每个 .c 拥有独立的宏环境与 include 状态，令牌携带原始文件与行号，展开后输出与源码行对齐的一行一段文本，因此 AST 行号可直接映射回原始源码。宏展开实现标准算法要点：参数替换、`#` 字符串化、`##` 拼接、`__VA_ARGS__`、蓝色集合式递归抑制、`defined` 与条件表达式短路求值（除零或非法位移只在被选中时诊断）。

多文件项目由 `src/engine/project.ts` 驱动 `preprocess`，各 .c 使用独立 Parser，再检查符号声明/定义并链接。求值器按当前翻译单元解析可见符号，文件级 static 保持私有；函数指针地址仍指向唯一实现。

展开行映射到原文件和原行，运行结束后将内部行号转换为 `Snapshot.file/line`、`Frame.file/line` 和 `Trace.errorFile/errorLine`。因此头文件插入不会让编辑器高亮偏移。项目包含关系仅作源码结构说明，不冒充实际调用轨迹。

## 2b. 执行边界与保护

- 解析失败给出**行号与附近语法错误**，错误位置与源码一致。
- 单次执行限制：8 秒、400,000 次操作、16,000 字符输出、32,000 字符源码、8,000 字符标准输入；快照采用滑动缓冲区，滚动保留最近 1,500 步。
- 轨迹带源码版本标记；改代码后旧轨迹置为 stale，需重新运行。
- 执行任务与动画播放解耦；暂停动画不等于底座程序暂停。

## 3. 自有模块保持简单

| 模块 | 职责 | 不负责 |
|---|---|---|
| CourseCatalog | 课程、前置知识、例子和讲义 | 解释 C |
| EngineAdapter | 调度 Web Worker、组装 Trace、超时与错误映射 | 解释 C |
| Preprocessor（`src/engine/c/preprocess.ts`） | 注释与续行、宏展开、条件编译、include、原始行映射 | 求值与绘图 |
| c-engine（`src/engine/c/`） | 解析适配、类型系统、字节内存、求值、标准库 | 绘图与播放 |
| LessonModel | 受控参数对应的概念模型 | 理解任意修改后的源码 |
| Playback | 步骤索引、速度、回放和跳转 | 修改程序语义 |
| Visualizers | 变量、数组、关系和架构图 | 从动画反推数据 |
| ProjectStorage | 本地保存、导入、导出和版本 | 在线用户与班级系统 |

先保持一个应用，不拆微服务，不需要任何后端；所有执行都在浏览器的 Web Worker 里完成。

## 4. 绘图与动画

- 常规教学图：DOM/SVG，可选择、可缩放、易生成文本替代。
- 模块依赖：节点少且位置固定时直接 SVG；需要拖动、缩放、连线时用 React Flow。
- 讲义的流程、状态、时序图：Mermaid。
- 通用 UI 动效可使用 Motion 的开源核心或 CSS；教学回放必须由可寻址的步骤/进度驱动，不依赖自由运行的动画队列。
- 不需要 WebGL、3D 引擎、视频渲染管线或图像生成服务。

## 5. 最小正确性约束

- 所有步骤带源码版本和来源：`engine`、`lesson-model` 或 `authored-diagram`。
- 引擎没有暴露条件结果时，只展示它提供的停点与值，不补造分支事件。
- 教学模型源码被手工修改后失效，直到重新验证或恢复场景。
- 执行任务与动画播放解耦；暂停动画不等于底座程序暂停。
- 浏览器可运行部分放 Web Worker，设步骤/时间/输出限额，停止时终止 worker。
- 若引擎还依赖本地原生源码转换工具，给转换进程设置资源与路径限制；不因没有 GCC 运行就认为毫无隔离需求。
- 不把学生源码传到第三方网站作为默认实现。

## 6. 不作为首版前置的技术

GDB/MI、LLVM 插桩、通用堆追踪、寄存器仿真、全平台 ABI 适配、完整预处理器与构建系统、线程与异步。

自研求值器已是既成事实，但它的目标是**教学可见性**而非 C 兼容性：只为可观测的教学语义服务，不追求完整 C17 或任何 ABI 的位级一致。

原生 GCC 仍适合验证课程正常程序、生成预期输出和附带多文件练习；无需与每个教学动画实时绑定。本项目的回归测试正是这样用 GCC 的。
