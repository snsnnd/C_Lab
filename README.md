# C Lab · C 语言可视化实验室

**左侧写代码，右侧看变化。** 面向大一新生的 C 语言教学工作台：代码在浏览器里真实解释执行，右侧用变量盒、数组格、指针箭头和调用层展示每一步发生了什么。

当前共 **23 节课程：14 节 C 基础课 + 4 节架构模块课 + 4 节常用进阶课 + 1 个综合系统**。支持宏、条件编译、多文件编辑与链接、跨文件回放，最终章是可运行的学生成绩管理系统。

## 快速开始

```bash
npm install
npm run dev        # 开发模式，打开 http://localhost:5173
```

其他命令：

```bash
npm run build      # 构建静态产物到 dist/
npm run preview    # 预览构建结果（端到端测试使用）
npm test           # 执行器、快捷键与课程测试；GCC 对照测试需要 gcc
npm run test:e2e   # 浏览器端到端测试，先运行 npm run build
```

部署给学生时，只需分发 `dist/` 目录并用任意静态服务器托管；执行发生在学生自己的浏览器内，不需要服务器编译，也不需要联网。

## 分发包与部署

重新生成可分发压缩包（含启动脚本与使用说明）：

```bash
npm run build
npm run package     # 生成 release/C-Lab-web-<日期>.zip
```

压缩包解压后双击启动脚本即可使用：Windows 用 `启动-Windows.bat`，Linux / macOS 用 `start-linux-mac.sh`（调用系统自带的 Python 3 或 Node.js 起一个本机静态服务器）。不能直接双击 `index.html`：浏览器禁止 `file://` 页面加载 WebAssembly 与 Worker。

部署到服务器时把包内 `index.html` 与 `assets/` 复制到静态目录即可（nginx / Apache / Caddy 均可）。建议入口不缓存、资源长缓存：

```nginx
location = /index.html { add_header Cache-Control "no-cache"; }
location /assets/     { add_header Cache-Control "public, max-age=31536000, immutable"; }
```

多人同时访问没有并发压力：网页是纯静态的，每个访问者在自己的浏览器里独立执行代码，互不影响，服务器只发送文件。更新版本时覆盖文件，访问者刷新页面即可生效；已经打开的页面不会自动刷新。

## 课堂同步（老师操作，学生跟随）

仓库自带一个零依赖的 Node 同步服务（`server/serve.mjs`，静态托管 + SSE 推送）：

```bash
npm run build
npm run serve       # 默认 0.0.0.0:8000，会打印本机与局域网地址
```

老师用 `http://localhost:8000` 打开页面，点右上角「课堂同步 → 开始共享」，得到 6 位课堂码与加入链接（即使老师在 localhost 上打开，链接也会自动使用服务检测到的局域网地址，学生设备可直接打开）；学生用同一局域网的地址（或任何能访问该服务器的地址）打开链接，页面进入**只读跟随**：课程切换、全部源码、标准输入、播放步骤会实时同步，右上角显示在线人数。学生点「退出跟随」即可恢复自由编辑。

学生加入课堂前，本机代码会先备份；退出跟随后自动恢复自己的版本。即使上课中途关闭页面（没有点退出），下次打开也会恢复备份，不会因为跟随老师而丢掉自己的代码。

- 协议：老师用 `POST /api/publish` 上报 `workspace`（课程 + 文件 + 输入，400 ms 防抖）与 `step`（播放位置，80 ms 节流）两类消息；学生通过 `GET /api/events` 的 SSE 流接收，断线由 EventSource 自动重连并由服务端重放当前状态。
- 安全：首次上报注册共享密钥，之后只有同一密钥能继续发布；房间码为 6 位、无易混字符。服务只在内存中保存每个房间的最后状态，不落盘，60 分钟无活动自动清理。
- 反向代理：nginx 等需对 `/api/events` 关闭缓冲（`proxy_buffering off`），否则事件会被攒着不推送。
- 纯静态部署（不带 Node 服务）时课堂同步按钮不可用，其余功能完全不受影响。

## v0.1 已实现

- **左右分屏工作台**：CodeMirror 6 编辑器 + 运行可视化，支持拖动比例外的自适应布局；任一侧可一键全屏（Esc 还原），投屏讲解更清楚。
- **真实执行**：源码在 Web Worker 中解释执行，所有图示来自本次执行的真实状态。
- **可视化元素**：控制流决策（分支命中、循环轮次、未走的路径置灰）、标量变量盒、数组格与索引游标、结构体字段（含字节偏移）、指针与函数指针指向关系、嵌套函数调用层、枚举常量名、本步变化高亮与前后值。
- **左右同步**：左侧高亮行就是右侧图示报告的停点行，两者由同一个快照驱动，逐步播放时同步移动。
- **时间控制**：播放/暂停、上一步/下一步、首尾跳转、时间轴拖动、0.5×–2× 变速。
- **双视图**：图形视图与无障碍状态表视图切换。
- **14 个课程**：变量、判断、循环、数组、函数、字符串、指针、输入、循环控制、结构体、结构体指针、枚举、回调，含讲解、预测题与动手任务。
- **4 节架构课**：从单文件到模块、封装与状态所有权、分层与依赖方向、用接口替换策略。每课含可编辑的 .c/.h 文件及实际执行轨迹。
- **进阶与最终章**：宏定义与展开、条件编译、静态局部变量与位标志、动态内存，以及学生成绩管理系统。宏课可直接查看运行前的预处理结果。
- **项目编辑**：文件切换、新增、重命名、删除；跨模块回放自动切到对应源码；完整项目以 JSON 导入导出，本地保存所有文件。
- **课程讲义**：概念说明、常见的坑、再深一层、预测题与参考解释、学完标记。
- **标准输入**：预设输入面板，配合 `scanf` 示例。
- **工程体验**：本地自动保存、源码导入导出、恢复示例、修改后旧图示标记为过期。
- **课堂功能**：投屏模式（放大代码与数值）、深浅主题、减少动画开关、课程目录与进度、**课堂同步**（老师操作、学生只读跟随，见上文）。
- **执行保护**：8 秒超时终止、1500 步上限、16000 字符输出上限、无效语法明确拒绝。

## 执行器与能力边界

### 快捷键

点击页脚「快捷键」或按 `?` 查看完整列表。

| 按键 | 操作 |
|---|---|
| Ctrl / ⌘ + Enter | 运行代码或整个项目 |
| Ctrl / ⌘ + . | 停止执行，并暂停回放 |
| Space | 播放 / 暂停 |
| → / ← | 下一步 / 上一步 |
| Shift + Space | 上一步 |
| Home / End | 第一 / 最后一步 |
| Alt + → / ← | 编辑器内也可单步 |
| ? / Esc | 打开快捷键帮助 / 关闭弹层 |

输入时保留空格、普通方向键与 Home/End 的文本编辑行为；弹窗内不会触发后台运行和回放。过期轨迹需重新运行后才能播放。

### 多文件教学项目

在课程目录的「软件架构 · 可运行的 C 模块」选择第 15–18 课。也可以在任意课程新增 .c/.h 文件。

- 各 `.c` 独立展开本地 `#include "name.h"`、独立解析，随后链接函数与全局对象；不是把源码直接拼成一个翻译单元。
- 支持函数声明/定义、跨文件函数指针调用、`extern` 共享全局对象、文件级 `static` 私有函数与变量。重复定义、声明类型冲突、缺失头文件等会给出诊断。
- 支持对象宏、函数式宏、嵌套展开、续行、字符串化 `#`、记号拼接 `##`、可变参数 `__VA_ARGS__`、`#undef`；宏环境按翻译单元隔离。
- 支持 `#if/#ifdef/#ifndef/#elif/#else/#endif`、`defined`、整数与位运算条件、头文件保护、`#pragma once`、`#error`、宏指定的 include、`__LINE__` 与 `__FILE__`。
- 最多 24 个平级文件，源码合计 32,000 字符，展开后每个翻译单元最多 128,000 字符。UI 保留入口文件名 `main.c`；没有子目录和构建系统。
- 「源码包含关系」来自当前源码；调用层和文件停点来自实际执行。包含关系不等于函数调用方向。
- 导出单文件为 `.c`，导出多文件为包含 `files` 与 `input` 的 `.json`。重命名文件后需手动更新对应 `#include`。

代码由 **[tree-sitter-c](https://github.com/tree-sitter/tree-sitter-c)**（MIT）解析成语法树，再由本项目的**逐步求值器**在 Web Worker 中执行。

这不是「装一个开源引擎」，而是一份实测后的选择：

| 候选 | 结构体 | 枚举 | 函数指针 | 浏览器内自由改代码 | 结论 |
|---|---|---|---|---|---|
| JSCPP 2.0.9 | ✗ | ✗ | ✗ | ✓ | 能力不足，已移除 |
| persistent-c + c-to-json | ✓ | ✗ | ✗ | ✗（需原生二进制） | 实测不支持 enum 与函数指针 |
| Codecast 整套 | ✓ | ✗ | ✗ | ✗（需服务器与凭据） | 部署成本过高 |
| **tree-sitter-c + 自研求值器** | ✓ | ✓ | ✓ | ✓ | **采用** |

求值器实现了**扁平字节内存**，因此指针别名、数组连续性、结构体字段偏移、`sizeof` 与指针宽度都按真实内存模型计算，而不是用 JavaScript 对象近似。布局遵循 x86-64 System V ABI，界面会标注这一点。

### 与 GCC 的对照

引擎输出与 `gcc -std=c17` 编译运行的结果做过逐行对照，覆盖结构体数组、`sizeof`、结构体指针回调排序、整数除法、指针算术、`printf` 的 `%.2f`/`%5.1f` 对齐，全部一致。该对照已固化为回归测试（`src/engine/c-engine.test.ts`）。

### 已验证支持

变量与表达式、`if/else`、`switch`、`for/while/do`、`break/continue`、普通函数与递归、一维与二维数组、字符串、指针与指针算术、**结构体与结构体数组**、**结构体指针与 `->`**、**枚举**、**typedef**、**函数指针与回调**、结构体按值赋值、**静态局部变量**、位运算与 `bool`、定宽整数、`malloc/calloc/free`，以及 `printf`、`puts`、`putchar`、`scanf`、`sscanf`、`fgets`、`strlen`、`strcmp`、`strcpy`、`abs`、`exit`。`sizeof` 可作用于类型与数组，数组长度支持整数常量表达式。

**尚未支持**：`#line`、GNU 专用宏扩展、子目录与完整构建系统、位域、变长数组、线程，以及完整的文件 I/O 行为。标准库是教学子集，不等同于完整 C17 编译器；整数在 JavaScript 安全整数范围内讲解。

多文件课程（第 15–23 课）均在测试中用 `gcc -std=c17 -Wall -Wextra` 实际编译全部翻译单元，并与浏览器求值器输出对照；最终章的成绩管理系统还额外覆盖了容量不足、非法输入、重复学号与配置开关等边界（`src/engine/project-gcc.test.ts`、`src/engine/advanced-gcc.test.ts`）。

### 讲课时必须讲清的边界

1. 高亮行是解释器停点，**同一行的表达式可能产生多个状态**，不能讲成「每行只执行一步」或「这就是求值顺序」。
2. 数组游标是根据索引变量绘制的指示，**不代表检测到了一次内存读取**。
3. 指针箭头表示逻辑关系，**不是本机地址**；地址受平台和分配顺序影响。
4. 结构体的字节偏移按 x86-64 模型计算，换平台数值会变。
5. 暂停和回退只控制已有轨迹，**程序已经运行完毕**；输出窗口显示完整输出，不随回放撤销。
6. **未定义行为不会被自动检测**，例如越界读未初始化内存。
